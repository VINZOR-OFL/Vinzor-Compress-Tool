# ⚡ Vinzor Compress Tool - Smart Image Studio Pro

> **Live Website:** [https://vinzor-ofl.github.io/Vinzor-Compress-Tool/](https://vinzor-ofl.github.io/Vinzor-Compress-Tool/)

**Vinzor Compress Tool** is a fast, 100% client-side web utility built for Indian students, job applicants, and professionals. It allows users to batch-compress photos, convert formats, apply passport/govt exam presets, add name/date stamps, and clean scanned signatures directly inside the browser.

---

## 🚀 Key Features

* 🏛️ **Official Govt Exam Presets:** One-click auto-configuration for UPSC, SSC, NEET, Passport Seva, and GATE requirements.
* 📐 **Custom Dimension Resizer:** Force exact width and height dimensions in **Pixels (px)** or **Centimeters (cm)** at 300 DPI.
* 🎯 **Precision KB Target Compression:** Set custom size limits (e.g., under 20 KB, 50 KB, 200 KB, 1 MB).
* ✒️ **Name & Date Stamp Generator:** Overlay candidate name and date taken on a white banner at the bottom of passport photos.
* ✍️ **Scanned Signature Cleaner:** Turn gray/shadowed paper pure white while boosting blue/black ink contrast.
* ✂️ **Interactive Cropper & Filters:** Built-in cropping, rotating, and grayscale filters.
* 📦 **Batch Exporting:** Download individual files, bundle all optimized photos into a **.ZIP** archive, or merge them into a single **PDF**.
* 🔒 **100% Privacy:** Files are processed locally inside your web browser and are **never uploaded to any server**.

---

## 🛠️ Built With

* **HTML5 / CSS3 / JavaScript (Vanilla)**
* [jsPDF](https://github.com/parallax/jsPDF) - Client-side PDF generation

* [Cropper.js](https://github.com/fengyuanchen/cropperjs) - JavaScript image cropper
